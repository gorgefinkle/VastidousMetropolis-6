# Metropolis R14.38 — Mother Willow Wooden Scaffold

## Scope

Built on R14.37. This revision changes only Mother Willow's crown and branch
architecture. Lake and mountain teleport commands from R14.37 are retained.
The missile silo remains untouched.

## Willow correction

- Retains the poplar material palette and the deep, distributed lateral root
  system.
- Keeps the primary and secondary branch skeleton as continuous tapered wood
  all the way to its terminal tips.
- Removes repeated terminal forks and upright replacement crowns that created
  the dense branching cap.
- Reduces the number of primary scaffold arms and subordinate branches.
- Places leaf clusters and pendulous foliage only on the outer terminal crown,
  leaving the bole and inner crown open and visibly woody.
- Uses fewer, shorter, more widely spaced hanging shoots.

## Validation

The Java 25 workflow checks root depth, old-growth height, broad crown reach,
wood volume, absence of fence/oak blocks, and a low inner-crown foliage ratio.
It then builds the complete Paper plugin and packages one current JAR, the
full version-specific source ZIP, and SHA-256 checksums.

Geometry QA is not a substitute for visual in-game approval.
